TaxoAdapt를 활용한 LLM 기반 기술 분류 자동화

내재화 및 실증 사례 - AX User Conference 발표 사례 공유

탐구 배경

타 프로젝트에서 높은 효용성을 보인 TaxoAdapt 프레임워크 레퍼런스를 확인했습니다. 단순히 도구를 사용하는 것에 그치지 않고, 사내의 복잡한 기술 분류 체계 및 특허 분석 업무에 최적화된 형태로 내재화함으로써 실질적인 업무 프로세스의 혁신과 효율을 높이고자 본 과제를 추진하게 되었습니다.

내재화 방법

  • GPU 가상환경 기반 인프라 구축: Llama 모델의 원활한 구동을 위해 RunPod GPU 가상환경을 활용하여 모델 테스트 및 추론 최적화 단계를 거쳤습니다.
  • 아키텍처 로직 전면 재구성: 기존 TaxoAdapt의 특징인 바텀업(Bottom-up) 트리 생성 방식에서 탈피하여, 사내 표준 기술 분류 체계에 맞게 데이터를 정렬하는 탑다운(Top-down) 매핑 로직으로 핵심 엔진을 수정했습니다.

주요 발견: 성능 검증

"단순한 기술의 도입을 넘어, 사내 표준 체계에 맞춘 '고정 체계 매핑'과
환각을 통제하는 '단계적 추론'의 내재화가 진정한 AI 전환(AX)의 핵심이다."
